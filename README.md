Linear Search Algorithm Visualizer

PROJECT OVERVIEW

The Linear Search Algorithm Visualizer is a web-based application developed using Python, Flask, HTML, CSS, and JavaScript. It helps users understand how the Linear Search algorithm works by searching for a target element in an array and displaying the searching process step by step.

The application highlights checked elements, identifies the target element when found, displays the target index, and counts the number of comparisons performed.

OBJECTIVES
Understand the working of the Linear Search algorithm.
Visualize the searching process step by step.
Find the position of a target element in an array.
Calculate the number of comparisons required.
Learn algorithm time and space complexity.
Provide an interactive and user-friendly interface for learning data structures and algorithms.
FEATURES
Interactive web-based interface.
Search for any integer in a list of numbers.
Visual highlighting of checked and found elements.
Displays the target index and position.
Counts the number of comparisons.
Handles cases where the target element is not found.
Input validation and error handling.
Responsive design for different screen sizes.
TECHONLOGIES USED
Python: Implements the Linear Search algorithm.
Flask: Provides the web application backend and API.
HTML5: Structures the webpage.
CSS3: Styles the interface and array visualization.
JavaScript: Handles user interaction and displays search results.
Git and GitHub: Version control and project hosting.
ALGORITHM
Start from the first element of the array.
Compare the current element with the target.
If the element matches the target, return its index.
Otherwise, move to the next element.
Repeat until the target is found or the array ends.
If no match is found, return "Not Found."
